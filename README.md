# Shikimori franchise dark

**A userstyle for shikimori franchise section**

![shikimori franchise page preview](https://userstyles.world/preview/21880/0t.webp)

## Installation
[![Install directly with Stylus](https://img.shields.io/badge/Install%20directly%20with-Stylus-285959.svg)](https://raw.githubusercontent.com/eboboeing-747/main/shikimori-franchise-dark.user.css)

**or install by hand**

1. have [Stylus](https://github.com/openstyles/stylus) extension installed
2. go to [userstyles style homepage](https://userstyles.world/style/21880/shikimori-franchise-dark)
3. click install button

## Setting a custom background

1. go to `body` selector
2. replace `background-image` value with `url("path/to/your/bg.ext")`

```
body {
    /* ... */
    background-image: url("https://i.postimg.cc/RhwZhw9H/wallpaperflare-com-wallpaper.jpg") !important;
    /* replace this url with your image link ^^^ */
    /* ... */
}
```
